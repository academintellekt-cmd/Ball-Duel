# Ball Duel

Отдельное Windows/Electron-приложение для аттракциона Ball Duel в экосистеме StriveX.

## Оборудование

- Windows-сервер с сенсорным и дополнительным игровым экраном;
- USB RFID-считыватель, обслуживаемый StriveX Gateway;
- две USB joystick-платы — по одной на каждый стенд;
- две Arduino Nano — по одной для подсветки каждого стенда;
- пять колец и два датчика на кольцо в каждом стенде;
- 25 адресных светодиодов на кольцо, всего 125 на Arduino.

Подключение датчиков к каждой joystick-плате:

```text
Buttons 1–2  → Ring 1
Buttons 3–4  → Ring 2
Buttons 5–6  → Ring 3
Buttons 7–8  → Ring 4
Buttons 9–10 → Ring 5
```

Повторный сигнал кольца игнорируется во время двух вспышек (`700 мс`). Очко получает игрок, попавший в стенд соперника.

## Режимы

- **Свободная игра:** любое кольцо соперника даёт 1 балл.
- **Зелёные цели:** два зелёных кольца дают `+1`, красные дают `−1`. После попадания зелёная цель переносится.
- **Ценные кольца:** синее `+1`, зелёное `+2`, жёлтое `+3`. Раскладка меняется через 10/7/5 секунд. На экстремальном уровне используются 1 синее, 1 зелёное, 1 жёлтое и 2 красных кольца (`−1`).

## Arduino

Прошивки:

- `arduino/BallDuel_LED_Blue_Nano/BallDuel_LED_Blue_Nano.ino`;
- `arduino/BallDuel_LED_Orange_Nano/BallDuel_LED_Orange_Nano.ino`.

Установите `Adafruit NeoPixel`. DATA подключена к `D6`. Светодиоды питаются от отдельного БП 5 В; GND блока питания и Arduino объединяются. Не питайте 125 светодиодов от USB.

Идентификаторы: `BALL_DUEL_LED_BLUE` и `BALL_DUEL_LED_ORANGE`.

Поддерживаемые команды:

```text
IDENTIFY
IDLE B
IDLE O
SET BBGYR
FLASH 3 G 2
TEST
```

## Джойстики

По умолчанию синий стенд использует Gamepad index `0`, оранжевый — `1`. Настройка находится в `config.json`:

```json
"standByGamepadIndex": [0, 1]
```

Если стенды поменялись местами, укажите `[1, 0]` и перезапустите игру. У одинаковых HID-плат обычно нет уникального серийного номера, поэтому физические USB-порты желательно не менять.

## Музыка и звуки

```text
music/menu                 музыка меню
music/games/free           музыка свободного режима
music/games/targets        музыка зелёных целей
music/games/values         музыка ценных колец
music/effects/blue         звук синего кольца
music/effects/green        звук зелёного кольца
music/effects/yellow       звук жёлтого кольца
music/effects/red          звук красного кольца
music/bonus-x2.mp3         включение множителя X2
music/bonus-green.mp3      включение зелёных бонусных колец
```

Можно добавлять несколько файлов MP3/WAV/OGG/M4A/AAC.

## Установка и запуск

Рекомендуется Node.js 22 LTS.

```bat
cd /d "ПУТЬ_К_ПРОЕКТУ\ball_duel_windows"
npm install
npm run check
npm start
```

Или запустите `scripts\start-dev.bat`. Для проверки интерфейса без джойстиков используйте `scripts\start-interface-test.bat`.

Тестовые клавиши: `Q W E R T` — кольца синего стенда; `U I O P [` — кольца оранжевого стенда.

Сборка portable EXE:

```bat
scripts\build-exe.bat
```

## StriveX

Приложение подключается к локальному StriveX Gateway на `127.0.0.1:4210`. Gateway выполняет регистрацию RFID и передаёт двух игроков через событие `unlock`. При завершении сессии Ball Duel отправляет итоговый результат и историю режимов.

## Бонусы и контроллеры

- 10 правильных попаданий подряд включают X2 на 7 секунд.
- 20 правильных попаданий подряд включают все зелёные кольца игрока на 7 секунд; каждое попадание приносит 1 балл. В свободном режиме этот бонус отключён.
- Ошибочное попадание сбрасывает текущую серию.
- Две HID-платы назначаются синему и оранжевому стендам автоматически. Назначение сохраняется в локальных настройках. Если физические стороны требуется поменять местами, установите `gamepad.swapPlayers` в `true` в `config.json`.
